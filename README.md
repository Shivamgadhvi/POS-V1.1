Drop item photos here.

For example, to add a photo for "Classic Brownie":
1. Save the photo as `classic-brownie.jpg` in this folder.
2. Open `src/data/menuItems.js` and set that item's `image` field to `/images/classic-brownie.jpg`.

If an item has no photo, the app automatically shows a category icon instead — so you can add photos gradually without breaking anything.
